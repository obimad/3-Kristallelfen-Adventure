# Die 3 Kristallelfen

Ein illustriertes Browser-Adventure mit Rätseln, Gesprächen und Minispielen.

[Jetzt spielen](https://obimad.github.io/3-Kristallelfen-Adventure/)

Fina bewegt sich mit den Pfeiltasten oder per Mausklick. Gespräche beginnen bei der Ankunft. Die Reisetasche öffnet das Inventar; unten kann man Kapitel direkt auswählen. Der Ausgang erscheint nach der gelösten Aufgabe. Mit ♫ lässt sich der Klang einschalten.

Dieses Repository enthält das veröffentlichte Spiel im Ordner docs/, einschließlich der benötigten Bilder, Spielmusik und Kapitelmusik. GitHub Pages veröffentlicht diesen Ordner direkt aus dem Branch main. Buchquellen, Zugangsdaten, Entwicklungsunterlagen und die Historie des Entwicklungsprojekts gehören nicht zu diesem Paket.

Die Bilder, Geschichte und Musik sind Bestandteile des Spiels; ihre Veröffentlichung erteilt keine gesonderte Nutzungslizenz.
